TEST CASES
===========

TC-01: Successful Cash Withdrawal (Happy Path)
Maps to: AC-1
Pre-conditions:
  - User has a valid card linked to an account with balance >= $100.
  - ATM is online and stocked with $20 notes.
Steps:
  1. Insert card.
  2. Enter correct PIN.
  3. Select "Withdrawal".
  4. Select "Checking" account.
  5. Enter amount: $100.
  6. Confirm transaction.
Expected Result:
  - ATM dispenses exactly $100 in cash.
  - Account balance decreases by $100 (plus fee, if applicable).
  - Card is returned.
  - Receipt is offered and, if accepted, printed with correct amount and new balance.

TC-02: Card Retained After 3 Failed PIN Attempts
Maps to: AC-2
Pre-conditions:
  - User has a valid card.
Steps:
  1. Insert card.
  2. Enter an incorrect PIN.
  3. Observe error message and retry.
  4. Enter an incorrect PIN a second time.
  5. Observe error message and retry.
  6. Enter an incorrect PIN a third time.
Expected Result:
  - After attempts 1 and 2: ATM shows "Incorrect PIN, please try again" and allows retry.
  - After attempt 3: ATM displays a card-retained/blocked message, retains the card, and
    no cash is dispensed.

TC-03: Withdrawal Rejected for Insufficient Funds
Maps to: AC-3
Pre-conditions:
  - User has a valid card linked to an account with balance = $50.
Steps:
  1. Insert card and enter correct PIN.
  2. Select "Withdrawal".
  3. Select the account with $50 balance.
  4. Enter amount: $200.
  5. Confirm transaction.
Expected Result:
  - ATM displays "Insufficient funds" message.
  - No cash is dispensed.
  - Account balance remains unchanged at $50.
  - User is returned to the amount-entry screen.

TC-04: Withdrawal Declined Due to Insufficient ATM Cash
Maps to: AC-4
Pre-conditions:
  - User has a valid card with account balance >= $500.
  - ATM's remaining cash on hand is $300 (simulated/low-cash test rig).
Steps:
  1. Insert card and enter correct PIN.
  2. Select "Withdrawal".
  3. Select account.
  4. Enter amount: $500.
  5. Confirm transaction.
Expected Result:
  - ATM displays an error indicating it cannot dispense the requested amount
    (e.g., "Unable to dispense requested amount").
  - No cash is dispensed and the account is not debited.
  - Card is returned.

TC-05: Withdrawal Rejected for Exceeding Daily Limit / Response Time Within SLA
Maps to: AC-5
Pre-conditions:
  - User has a valid card; account has sufficient balance.
  - ATM daily withdrawal limit is $500; user has already withdrawn $450 today.
Steps:
  1. Insert card and enter correct PIN.
  2. Select "Withdrawal".
  3. Select account.
  4. Enter amount: $100 (would exceed remaining daily limit of $50).
  5. Confirm transaction.
  6. Separately, repeat TC-01 with a valid $100 withdrawal and measure elapsed time from
     confirmation to cash dispensing + card return.
Expected Result:
  - Step 5: ATM rejects the transaction before authorization, displays a message stating
    the remaining daily limit ($50), and does not debit the account.
  - Step 6: End-to-end transaction (authorization -> dispensing -> card return) completes
    within 30 seconds under normal network conditions.
