ACCEPTANCE CRITERIA
====================

AC-1 (Functional Success — Happy Path)
Given a user inserts a valid card and enters the correct PIN,
When they select an account, enter a withdrawal amount that is a valid note multiple,
within their available balance, within the ATM's per-transaction/daily limit, and the
ATM has sufficient cash on hand,
Then the ATM dispenses the exact requested amount in cash, debits the account by that
amount (plus any disclosed fee), returns the card, and offers a receipt.

AC-2 (Error Handling — Invalid PIN)
Given a user inserts a valid card,
When they enter an incorrect PIN,
Then the ATM displays an error message, allows retry up to 3 total attempts, and on the
3rd consecutive failure retains/blocks the card and does not dispense cash.

AC-3 (Error Handling — Insufficient Funds)
Given a user is authenticated and selects an account,
When they request a withdrawal amount greater than the account's available balance,
Then the ATM rejects the transaction, displays an "insufficient funds" message, does not
debit the account, and returns to the amount-entry screen.

AC-4 (Error Handling — Insufficient ATM Cash / Denomination Mismatch)
Given a user requests a valid, sufficiently-funded withdrawal amount,
When the ATM does not have enough physical cash or cannot dispense that amount using its
available denominations,
Then the ATM declines the transaction, displays a clear error message, does not debit the
account, and returns the card.

AC-5 (Performance & Limits — Transaction Timing and Withdrawal Limits)
Given a user submits a withdrawal request within posted per-transaction and daily limits,
When the request is processed,
Then the ATM completes authorization, dispensing, and card return within 30 seconds under
normal network conditions; and any request exceeding the per-transaction or remaining
daily limit is rejected before authorization with a message stating the applicable limit,
without debiting the account.
